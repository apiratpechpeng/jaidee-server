
== b1 หลายเรื่อง: เกรด + เพื่อน
  ❌ เกรดเทอมนี้ตกมาก แล้วเพื่อนสนิทก็ย้ายโรงเรียนไปอีก
      บอท: เรื่องเกรดกำลังวนอยู่ในใจสินะครับ
      บอท: อยากเล่าเพิ่มไหมครับ ว่าที่หนักใจที่สุดตอนนี้คืออะไร ตัวเกรดเอง เวลาที่มี คนที่ทำด้วยกัน หรือความคาดหวังของคนรอบข้าง
      -> ไม่ได้พูดถึง 'เพื่อน'
      -> ไม่อยู่ขั้น multi
  ✓ เรื่องเพื่อน
      บอท: เรื่องเพื่อน เข้าใจมากขึ้นเลยครับ ขอบคุณที่เล่าให้ฟังนะ
      บอท: อยากลองคิดทางออกด้วยกันไหมครับ หรืออยากเล่าเพิ่มก่อนก็ได้เลย

== b2 หลายเรื่อง 3 อย่าง
  ❌ ช่วงนี้แย่มาก สอบตกวิชาฟิสิกส์ พ่อกับแม่ทะเลาะกันทุกวัน แล้วยังนอนไม่ค่อยหลับอีก
      บอท: ฟังแล้วตอนนี้มีหลายเรื่องเข้ามาพร้อมกันเลยนะครับ ทั้งเรื่องผลสอบ และเรื่องพ่อแม่ทะเลาะกัน แบกไว้พร้อมกันแบบนี้คงเหนื่อยมาก
      บอท: อยากเริ่มคุยเรื่องไหนก่อนครับ หรือเรื่องไหนที่หนักใจที่สุดตอนนี้
      -> ไม่ได้พูดถึง 'ฟิสิกส์'
      -> ไม่ได้พูดถึง 'นอน'

== b3 ขอวิธีตอนยังไม่รู้ปัญหา
  ✓ เครียดเรื่องรายงานมาก
      บอท: เครียดเรื่องรายงานหนักเลยนะครับ เล่าออกมาแบบนี้ก็ดีแล้วนะ
      บอท: อยากเล่าเพิ่มไหมครับ ว่าที่หนักใจที่สุดตอนนี้คืออะไร ตัวรายงานเอง เวลาที่มี คนที่ทำด้วยกัน หรือความคาดหวังของคนรอบข้าง
  ✓ ต้องทำยังไงดี
      บอท: อยากช่วยคิดทางออกเรื่องรายงานด้วยครับ แต่ขอเข้าใจให้ตรงก่อนนิดนึง
      บอท: ตอนนี้ติดตรงไหนมากที่สุดครับ เช่น ยังไม่เข้าใจว่าต้องทำอะไร เวลาไม่พอ งานเยอะ หรือเรื่องคนในกลุ่ม
  ❌ ไม่รู้ว่าต้องเขียนอะไรบ้าง
      บอท: ไม่รู้ว่าต้องเขียนอะไรบ้าง เข้าใจมากขึ้นเลยครับ ขอบคุณที่เล่าให้ฟังนะ
      บอท: ถ้าอยากได้แนวทาง ผมช่วยคิดทางเลือกที่พอลองได้ด้วยกันได้นะครับ หรือถ้าอยากเล่าเพิ่มก่อนก็ได้เลย
      -> ไม่ได้ถามต่อ

== b4 ทางออกทีละขั้น
  ✓ ทำงานกลุ่มแล้วเพื่อนเทงานตลอด
      บอท: ต้องแบกงานกลุ่มอยู่คนเดียวทั้งที่เป็นงานของทุกคน มันทั้งเหนื่อยและน้อยใจนะครับ ไม่แปลกเลยที่จะเครียด
      บอท: เพื่อนในกลุ่มรู้ไหมครับว่าคุณรู้สึกแบบนี้ หรือยังไม่เคยได้คุยกันตรงๆ
  ✓ ไม่เคยบอกเขาเลย
      บอท: ไม่เคยบอกเขาเลย เข้าใจมากขึ้นเลยครับ ขอบคุณที่เล่าให้ฟังนะ
      บอท: อยากลองคิดทางออกด้วยกันไหมครับ หรืออยากเล่าเพิ่มก่อนก็ได้เลย
  ✓ มีวิธีไหม
      บอท: ได้ครับ ลองดูทางที่พอทำได้เรื่องงานกลุ่มที่ต้องทำคนเดียวกันนะครับ อย่างแรก ทำรายการงานที่เหลือ แล้วให้ทุกคนเลือกรับคนละส่วน พร้อมวันที่ต้องเสร็จครับ
      บอท: อย่างที่สอง บอกเพื่อนตรงๆ แบบไม่กล่าวโทษ เช่น ตอนนี้เราทำคนเดียวไม่ไหว อยากให้ช่วยกัน อีกอย่างคือ ถ้าคุยแล้วไม่ดีขึ้น ปรึกษาครูประจำวิชาว่าใครรับผิดชอบส่วนไหนครับ
      บอท: ข้อไหนที่พอจะลองได้มากที่สุดครับ เดี๋ยวช่วยวางขั้นแรกด้วยกัน
  ✓ ข้อแรกน่าจะลองได้
      บอท: ดีเลยครับ เริ่มจากก้าวเล็กๆ ก่อนนะ ขั้นแรกที่ทำได้วันนี้คือ พิมพ์รายการงานที่เหลือส่งในกลุ่มแชท แล้วชวนทุกคนเลือกงาน
      บอท: ไม่ต้องทำให้สมบูรณ์ แค่เริ่มก็นับแล้วครับ พอจะทำได้ไหม หรือมีอะไรที่ทำให้ยังไม่กล้าเริ่ม

== b5 ไม่กล้าทำตามทางเลือก
  ✓ ถูกรุ่นพี่ล้อเรื่องรูปร่างทุกวัน
      บอท: ถูกรุ่นพี่ล้อเรื่องรูปร่างทุกวัน มันทั้งเจ็บและไม่ปลอดภัยเลยนะครับ
      บอท: ถ้าอยากได้แนวทาง ผมมีวิธีที่พอลองได้อยู่ครับ อยากให้เล่าให้ฟังไหม หรืออยากระบายเรื่องที่เกิดขึ้นเพิ่มก่อนก็ได้นะ
  ✓ ขอวิธีรับมือหน่อย
      บอท: ได้ครับ ลองดูทางที่พอทำได้เรื่องการถูกล้อหรือแกล้งกันนะครับ อย่างแรก ลดเวลาดูรูปคนอื่นในโซเชียล เพราะรูปส่วนใหญ่ผ่านการแต่งมาแล้วครับ
      บอท: อย่างที่สอง เขียนสิ่งที่ชอบในตัวเองที่ไม่เกี่ยวกับหน้าตา 3 อย่าง อีกอย่างคือ ดูแลตัวเองด้วยสิ่งที่ทำให้สบายตัว ไม่ใช่เพื่อให้คนอื่นพอใจครับ
      บอท: ข้อไหนที่พอจะลองได้มากที่สุดครับ เดี๋ยวช่วยวางขั้นแรกด้วยกัน
  ✓ ไม่กล้าบอกครูอะ
      บอท: ไม่กล้าก็เข้าใจได้เลยครับ เรื่องแบบนี้ต้องใช้ใจเยอะ ลองแบบที่เล็กกว่านี้ไหมครับ แค่เลือก 1 อย่างที่ทำแล้วสบายตัว เช่น ดื่มน้ำ นอนให้พอ ยังไม่ต้องทำจริงทั้งหมดก็ได้
      บอท: ตรงไหนที่ทำให้รู้สึกว่ายากที่สุดครับ บอกได้เลย เดี๋ยวช่วยปรับให้เหมาะกับคุณ

== b6 เข้าใจปัญหาที่ต่างจากหัวข้อผิวเผิน
  ✓ อ่านหนังสือไม่เข้าหัวเลย พรุ่งนี้สอบแล้ว
      บอท: เรื่องการสอบกำลังวนอยู่ในใจสินะครับ
      บอท: อยากเล่าเพิ่มไหมครับ ว่าที่หนักใจที่สุดตอนนี้คืออะไร ตัวการสอบเอง เวลาที่มี คนที่ทำด้วยกัน หรือความคาดหวังของคนรอบข้าง

== b7 เรื่องที่บ้านต่อจากเรื่องเรียน
  ✓ การบ้านเยอะมากจนทำไม่หมด
      บอท: งานเยอะจนรู้สึกท่วมไปหมด ทำเท่าไหร่ก็เหมือนไม่หมดสักที เหนื่อยแบบนี้เข้าใจได้เลยครับ
      บอท: ตอนนี้มีงานค้างอยู่ประมาณกี่อย่างครับ แล้วอันไหนใกล้ส่งที่สุด
  ✓ แล้วแม่ก็ชอบด่าว่าเราขี้เกียจ
      บอท: นอกจากเรื่องงานที่เยอะแล้ว ยังมีเรื่องที่บ้านอีก หนักหลายทางเลยนะครับ ถูกแม่ด่า มันทั้งเจ็บทั้งอายนะครับ
      บอท: ก่อนจะคิดหาทางด้วยกัน อยากถามนิดนึงครับ เรื่องนี้เกิดขึ้นบ่อยแค่ไหน แล้วเป็นคนเดียวหรือหลายคนครับ

== b8 ตัดสินใจ
  ❌ อยากเรียนดนตรีแต่แม่อยากให้เรียนวิศวะ ควรเลือกทางไหนดี
      บอท: ฟังแล้วตอนนี้มีหลายเรื่องเข้ามาพร้อมกันเลยนะครับ ทั้งเรื่องความฝันของคุณ และเรื่องการต้องตัดสินใจเรื่องเรียน แบกไว้พร้อมกันแบบนี้คงเหนื่อยมาก
      บอท: อยากเริ่มคุยเรื่องไหนก่อนครับ หรือเรื่องไหนที่หนักใจที่สุดตอนนี้
      -> กล่องแรกไม่มีคำของผู้ใช้ ['ดนตรี', 'วิศวะ']

== b9 อกหัก ตอบรับข้อเสนอ
  ✓ แฟนนอกใจ เพิ่งรู้เมื่อวาน
      บอท: แฟนนอกใจ เพิ่งรู้เมื่อวาน มันเจ็บและค้างอยู่ในใจมากเลยนะครับ คนที่เคยสำคัญกับเรามากๆ พอไม่อยู่แล้ว ใจก็โหวงไปหมด
      บอท: เรื่องนี้เกิดขึ้นนานแค่ไหนแล้วครับ แล้วตอนนี้อะไรที่ค้างอยู่ในใจที่สุด
  ✓ คบกันมาสองปี
      บอท: คบกันมาสองปี แบกเรื่องนี้มาสักพักแล้ว คงเหนื่อยไม่น้อยเลยนะครับ
      บอท: อยากลองคิดทางออกด้วยกันไหมครับ หรืออยากเล่าเพิ่มก่อนก็ได้เลย
  ✓ อยากได้ทางออก
      บอท: ได้ครับ ลองดูทางที่พอทำได้เรื่องการเลิกกับแฟนกันนะครับ อย่างแรก ให้เวลาตัวเองเสียใจได้ ไม่ต้องรีบหายภายในวันสองวันครับ
      บอท: อย่างที่สอง พักจากการส่องโซเชียลของเขาสักระยะ ใจจะได้ไม่วนกลับไป อีกอย่างคือ นัดเพื่อนสนิททำอะไรด้วยกัน จะได้ไม่ต้องอยู่กับความเศร้าคนเดียวครับ
      บอท: ข้อไหนที่พอจะลองได้มากที่สุดครับ เดี๋ยวช่วยวางขั้นแรกด้วยกัน

== b10 ไม่สับสน
  ✓ วันนี้สอบได้ที่หนึ่งของห้อง ดีใจมาก
      บอท: วันนี้สอบได้ที่หนึ่งของห้อง ดีใจมาก ฟังแล้วพลอยดีใจไปด้วยเลยครับ
      บอท: เล่าเพิ่มอีกหน่อยได้ไหมครับ ตรงไหนที่ชอบที่สุด
